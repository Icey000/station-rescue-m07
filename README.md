# 停电救援：M-07

英文名：**Station Rescue: M-07**  
课程版本：**A1.0**

这是一个无需安装依赖、打开浏览器即可运行的游戏原型。

## 游戏目标

在停电的 M-07 车站中，使用方向键或 WASD 移动救援员，收集 3 个应急电池并返回出口。

- 绿色方块：救援员
- 黄色圆点：应急电池
- 蓝色方块：出口
- 红色方块：危险区域，碰到会损失生命

## 运行方式

直接双击 `index.html`，或在仓库页面点击绿色 **Code** → **Open with GitHub Desktop** 后，在本地打开 `index.html`。

也可以使用任意静态文件服务器运行：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 操作

- 移动：方向键 / WASD
- 重新开始：点击“重新开始”按钮

## 课程版本

A1.0：基础移动、收集目标、危险区域、胜负状态和重新开始功能。
