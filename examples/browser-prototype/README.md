# 早期浏览器小样 / Earlier browser prototype

这是建仓时已有的独立二维 Canvas 小样，保留其原始代码与历史说明。当前课程游戏是根目录的 Unity 3D 工程，玩法与验收记录以根目录 README 为准。

This separate 2D Canvas prototype was present when the repository was created. Its original code and README are preserved. The current course game is the Unity 3D project at the repository root.

双击 / Open `index.html` to try this prototype. It uses WASD / arrow keys, three collectible batteries, hazards, and a restart button.
