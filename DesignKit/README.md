# 游戏设计工作台

双击 index.html 用浏览器打开，或使用本轮 Codex 旁边的本机预览。无需安装库，也不需要连接 AI 服务。

1. “这次做到哪了”对应原课程 PDF 与实际进度，是带日期的快照。
2. “8 条设计经验”把本次问题映射到下一份需求；每条可跳到相关字段。
3. “构思 → Prompt”中选“新项目空白模板”，填写真正确定的内容，选择先设计/直接实现/验收修复，生成后复制给模型。
4. 浏览器会保存构思；换电脑/浏览器时用导出、导入 JSON。下载 TXT 可保留给模型的完整需求。
5. 试玩后将问题写成“前提 → 输入 → 预期”，补到下一轮需求。空白字段会明确列为待确认，不自动继承示例的故事和数值。

examples 是从实际页面导出的停电救援构思与 Prompt，可导入或编辑。resources 保留课程原 PDF、两页英文问题复盘草稿和进度证据。复盘需本人阅读、补充理解后提交。

game-design-brief 是可携带的 Skill，已有本机个人库副本。支持 Skill 的工具可加载它；其他模型可直接接收生成的 Prompt 或规则文件。技能与页面不自动发布仓库、上传作业或修改工程。

这是离线可复制的工具包。将整个 DesignKit 文件夹复制到下一项目，仍可打开 index.html；其中进度是本次项目快照，新的构思与目标由表单决定。
